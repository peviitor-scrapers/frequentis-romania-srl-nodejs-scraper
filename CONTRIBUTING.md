# Contributing

Thank you for your interest in contributing!

## 🌱 This Repo Is a Derived Scraper

This scraper was derived from the [EPAM template](https://github.com/sebiboga/epam-systems-international-srl-nodejs-scraper). Shared conventions and the derivation playbook live there.

## Development Setup

```bash
npm install
npm test
```

## Reporting Issues

Open a [GitHub Issue](https://github.com/peviitor-scrapers/frequentis-romania-srl-nodejs-scraper/issues) with:
- Clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
